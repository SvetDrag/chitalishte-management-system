DEMO / SEED DATA — Chitalishte Management System
==================================================

Both applications ship an optional demo-data seeder (DataSeeder), disabled
by default. When enabled, each app wipes its own database on startup and
inserts the fixed dataset described below.

HOW TO ENABLE
-------------
1. Add this line to the app's local properties file:

       app.seed.enabled=true

   Main app        -> src/main/resources/application-local.properties
   rental-service  -> rental-service/src/main/resources/application-local.properties

   (Alternatively, without editing files: run with
   -Dapp.seed.enabled=true, or set the environment variable
   APP_SEED_ENABLED=true, or add it under the "environment:" section of
   the relevant service in docker-compose.yml.)

2. Start (or restart) the application. The seeder runs once on startup
   and logs "Seeding ... database with demo data..." / "... seeding
   complete." in the console.

WARNING: the seeder DELETES all existing rows in its tables before
inserting the demo data. Do not enable it against a database whose data
you want to keep. It is meant for a fresh local/demo database only.
